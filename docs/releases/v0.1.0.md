# v0.1.0 — Initial Public Alpha

ToolBoundary is a local runtime policy boundary for AI agents and LLM tool-calling workflows.

> **Control what an AI agent can do at the tool boundary, before the tool executes.**

## Included
- Tool-level permissions and access modes
- Operation blocklists
- Transaction value ceilings
- Record-count ceilings
- Global and per-tool rate limits
- Autonomy-level controls
- Time-bounded policy validity
- Environment restrictions
- Custom policy hooks
- Emergency kill switch
- Structured audit events
- Logging, JSONL, and webhook audit sinks
- `@guarded_tool` decorator
- LangChain `BaseTool` integration
- Network/token enforcement modules
- Public API documentation

## Security Boundary
ToolBoundary is an application-layer control. It protects calls that are routed through the boundary and does not replace scoped credentials, operating-system permissions, network controls, or workload isolation.

## Project Status
This is an early-stage open-source alpha. Interfaces and integrations may evolve as the project develops.
